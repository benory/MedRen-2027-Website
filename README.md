# MedRen Leuven 2027

This repository contains the website for the Medieval and Renaissance Music Conference in Leuven, Belgium, 5–9 July 2027.

The site is intentionally a simple, single-page Jekyll website. Conference information can be updated in `index.html`, with shared styling in `assets/css/style.css`.
